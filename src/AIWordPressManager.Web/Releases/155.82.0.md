# AI WordPress Manager 155.82.0

Branch: `main`

## Site ownership hardening

- Enforced site ownership before every WordPress synchronization.
- Enforced site ownership before reading a site's cached content explorer data from SQLite.
- Direct navigation with another user's `SiteId` now fails before any local data is returned.
- Synchronization jobs are created only after the requested site passes the ownership check.
- Existing live WordPress API ownership protection remains active as a second security layer.
