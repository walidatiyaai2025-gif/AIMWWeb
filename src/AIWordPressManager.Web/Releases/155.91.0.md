# AI WordPress Manager Web 155.91.0

Branch: `main`

## Owned-site execution workspace

- Scoped `/module/execution` to WordPress sites owned by the signed-in user.
- Added a site selector and support for the `siteId` query parameter.
- Hid seeded or unrelated execution jobs from the current account.
- Filtered activity entries to the jobs visible for the selected owned site.
- Added ownership validation before pause, resume, retry, or cancel actions.
- Added a direct synchronization action for the selected site.
- Added an onboarding empty state when the account has no registered sites.
- Updated execution counters so they reflect the selected site scope only.
