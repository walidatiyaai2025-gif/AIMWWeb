# AI WordPress Manager 155.87.0

Branch: `main`

## Workspace-aware media and taxonomy

- Added `siteId` query-string support to the global Media Explorer.
- Added `siteId` query-string support to the global Categories & Tags Explorer.
- Switching the active workspace now filters media, categories, and tags to the selected owned WordPress site.
- Changing the workspace while either screen is open resets pagination and reloads the matching local cache.
- Selecting All sites removes the workspace filter and restores the cross-site view.
- Existing user ownership restrictions remain enforced by the underlying explorer services.
