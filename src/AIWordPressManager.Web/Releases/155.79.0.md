# AI WordPress Manager 155.79.0

Branch: `main`

## Account registration

- Added a public `/register` page.
- Added local account creation with duplicate username protection.
- Added password validation requiring at least eight characters, uppercase, lowercase, and a number.
- New accounts receive the `User` role instead of administrator access.
- The seeded `Admin` account remains an `Administrator`.
- After registration, users are redirected to sign in before adding their own WordPress sites.
