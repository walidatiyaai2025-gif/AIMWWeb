# AI WordPress Manager 155.94.3

Maintenance-only patch. No new features were added.

## Fixed

- Deferred the query-driven WordPress users load until the owned-site list has finished loading.
- Ignored query-string `siteId` values that are not present in the signed-in user's owned sites.
- Prevented premature REST calls and unstable error states when opening `/module/users?siteId=...` directly.
