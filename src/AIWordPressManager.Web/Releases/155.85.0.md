# AI WordPress Manager 155.85.0

Branch: `main`

## Workspace navigation

- Added an owned-site workspace switcher inside the authenticated account menu.
- The switcher lists only WordPress sites owned by the signed-in application user.
- The selected workspace is stored per application user in browser local storage.
- Added quick links from the active workspace to the site dashboard, content explorer, and site settings.
- Selecting `All sites` clears the stored workspace and returns to the sites overview.
- New accounts with no connected sites receive a direct link to the first-site onboarding flow.
- User name and role continue to come from the authenticated claims rather than fixed UI values.
