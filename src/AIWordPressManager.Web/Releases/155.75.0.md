# Version 155.75.0

Branch: `main`

## Added

- Global WordPress Users Workspace at `/module/users`.
- Site selector with live WordPress user loading.
- Search by username, display name, and email.
- Role filtering for administrator, editor, author, contributor, and subscriber.
- Current-page role summaries and WordPress pagination.
- Direct navigation to the full per-site users manager.

## Notes

User data is loaded live from the selected WordPress site and is not presented as offline SQLite data.
