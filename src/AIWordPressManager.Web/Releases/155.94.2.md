# AI WordPress Manager v155.94.2

Maintenance-only release. No new application features were added.

## Reliability fixes

- Simplified the install/update PowerShell script to reduce accumulated branching and repeated logic.
- Validates the Git branch name before using it in fetch and ref operations.
- Fetches and verifies the exact latest `origin/<branch>` commit before restore or build.
- Selects only solution and project files tracked by the current Git branch.
- Uses directory-boundary checks when associating the Web project with the selected solution.
- Cleans `bin` and `obj` only for tracked projects instead of recursively touching unrelated or old project copies.
- Avoids deleting untracked server configuration, certificates, data, logs, or environment files.
- Prevents duplicate `safe.directory` entries where possible.

## Verification status

The repository changes were reviewed statically. A clean Windows Server build and runtime execution still require confirmation in the target environment.
