# AI WordPress Manager Web 155.92.0

Branch: `main`

## Owned-site automation schedules

- Added a real `/module/schedules` and `/automation-schedules` workspace.
- Uses the existing SQLite automation engine instead of the placeholder module UI.
- Lists and controls schedules only for WordPress sites owned by the signed-in user.
- Supports synchronization and SEO audit jobs.
- Supports hourly, daily, weekly, and monthly recurrence, UTC run time, interval, retries, and enabled state.
- Supports create, edit, enable, disable, queue now, refresh, and delete operations.
- Supports the active workspace through the `siteId` query parameter.
- Added ownership checks before every schedule mutation.
- Restored the `CurrentUserContext.RequireUserId()` contract used by protected WordPress services.

## Known follow-up

- The hosted automation worker still needs an explicit site-owner execution context for fully isolated multi-user background execution. The management workspace is isolated; this worker-hardening step remains pending.
