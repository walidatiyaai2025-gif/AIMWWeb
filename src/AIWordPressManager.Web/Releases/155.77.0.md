# AI WordPress Manager 155.77.0

Branch: `main`

## Security

- Enforced site ownership inside the shared WordPress REST API client.
- Prevented direct access to another user's WordPress connection by guessing a site GUID.
- Isolated global posts and pages cache queries by the signed-in user.
- Isolated global media cache queries by the signed-in user.
- Isolated global categories and tags cache queries by the signed-in user.
- Updated the WordPress REST client user-agent version.

## Multi-user behavior

Every live WordPress request and the main global cached-content explorers now operate only on sites owned by the authenticated application user.
