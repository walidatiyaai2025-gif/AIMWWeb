# AI WordPress Manager 155.88.0

Branch: `main`

## Workspace-aware live WordPress data

- Added `siteId` query-string support to the global Comments Workspace.
- Added `siteId` query-string support to the global WordPress Users Workspace.
- Selecting a site from the workspace switcher now loads comments and WordPress users for that site automatically.
- Switching workspaces clears results from the previous site before loading the new site.
- Selecting **All sites** clears the live site selection without exposing data from another account.
- Existing ownership validation in `WordPressApiClient` remains enforced for every live REST request.
