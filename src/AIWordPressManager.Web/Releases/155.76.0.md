# Version 155.76.0

Branch: `main`

## User ownership foundation

- Added `OwnerUserId` to WordPress site profiles.
- Added a scoped current-user context based on authenticated claims.
- New sites are assigned to the signed-in application user.
- Site lists, summaries, credentials, updates, connection tests, disabling, and deletion are restricted to the owner.
- Existing unowned sites are assigned automatically to the default Admin account during startup.
- SQLite databases created by older versions receive the ownership column and index automatically.

## Security note

This release establishes ownership at the site-management service boundary. Direct content and operational services that accept a site identifier will receive the same centralized ownership guard in the next hardening release.
