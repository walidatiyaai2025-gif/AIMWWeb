# AI WordPress Manager 155.81.0

Branch: `main`

## Automatic initial synchronization

- The site onboarding workflow now performs the initial WordPress synchronization automatically after a successful connection test.
- Posts, pages, categories, tags, and media are downloaded into the local SQLite database before the user opens the site dashboard.
- Synchronization progress is shown as a separate onboarding stage.
- A failed initial synchronization no longer removes or invalidates the connected site.
- Users can retry the initial synchronization without re-entering the WordPress Application Password.
- Ownership is verified before the synchronization starts.
