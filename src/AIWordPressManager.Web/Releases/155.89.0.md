# AI WordPress Manager 155.89.0

Branch: `main`

## Workspace-aware Content Hub

- Added `siteId` query support to `/content` and `/module/content`.
- Content totals, cache freshness, and site rows now respect the active workspace.
- The service validates ownership by filtering through the signed-in user's sites.
- Posts, pages, media, taxonomy, and synchronization links preserve the active `siteId`.
- Added an **All sites** action to leave the selected workspace.
- Invalid or inaccessible site identifiers return an empty workspace without exposing another user's data.
