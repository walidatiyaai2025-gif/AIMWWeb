# AI WordPress Manager Web 155.90.0

Branch: `main`

## Real synchronization workspace

- Replaced the placeholder `/module/sync` module with a functional WordPress synchronization screen.
- Supports the active workspace through the `siteId` query parameter.
- Lists only WordPress sites owned by the signed-in user.
- Displays locally cached posts, pages, media, categories, tags, and the last synchronization time.
- Runs the existing ownership-protected synchronization service.
- Shows skipped, successful, and failed synchronization results.
- Refreshes local cache totals after synchronization.
- Provides direct links to the site content explorer, content hub, and offline data snapshot.
