# Laravel AIWMWeb AI Knowledge System

Purpose: make project understanding repository-native so a new ChatGPT/Codex worker can operate correctly without private chat memory.

This directory separates:

- stable project identity and architecture;
- dynamic project state;
- durable engineering decisions and conventions;
- recurring known risks;
- task-specific execution skills;
- handoff checkpoints.

## Start here

Read, in order:

1. repository-root `AGENTS.md`;
2. `.pcc/managed-repository-control.json` (standalone Laravel project routing);
3. `variants/laravel-aiwmweb/AGENTS.md`;
4. `.ai/PROJECT.md`;
5. `.ai/CURRENT_STATE.md`;
6. `.ai/SKILL_ROUTER.md`;
7. only the relevant files under `.ai/skills/`.

For autonomous project movement, also read `docs/REPO_OPERATING_SYSTEM.md`.

## Canonicality

These files improve reconstruction and consistency, but they do not replace live GitHub, PCC routing, the owner-approved Laravel-only roadmap (#3), current Laravel release gate (#1408), or exact-head CI. Historical #257 and archived-source parity records remain provenance only.

The project should become easier for AI to operate over time because verified lessons are promoted into repository knowledge. The model is replaceable; the repository is the durable memory.
