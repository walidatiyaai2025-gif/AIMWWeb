# Skill: Feature Closure

## Trigger
Port or complete one canonical Laravel AIWMWeb capability/operation.

## Procedure
1. Reconstruct composition, active handoff/PR ownership, exact canonical operation, source ASP.NET behavior, and dependencies.
2. Continue existing lineage; otherwise claim/create exactly one leaf under repository rules.
3. Trace the full vertical path: visible control/route -> auth/tenant -> service/domain -> persistence/external boundary -> authoritative refresh/evidence.
4. Preserve source semantics unless the Laravel adaptation has a documented reason.
5. Implement real behavior; no placeholder, toast-only, sample, or fabricated success.
6. Add focused deterministic tests, including tenant/authorization tests for tenant-owned operations.
7. Register machine-readable closure evidence.
8. Run the official materializer/reconciliation and prove exactly the intended operation changed.
9. Run every required exact-head PR gate.
10. Merge normally to the composition branch only when green, then verify post-merge exact-head gates and advance handoff.

## Learn
Promote only proven reusable lessons. Do not record operation-specific UI wording as a global convention unless repeated.
