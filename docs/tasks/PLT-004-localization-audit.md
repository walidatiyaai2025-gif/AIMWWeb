# PLT-004 Localization Audit

## Feature
Arabic RTL and English LTR completion audit.

## Scope
- Review all user-facing strings.
- Verify missing Arabic translations.
- Verify LTR/RTL layout switching.
- Check validation and error messages.
- Avoid hard-coded UI text where localization resources exist.

## Acceptance Criteria
- All main screens have Arabic and English text.
- Direction changes correctly with selected language.
- No functional regression from localization changes.
- Build verification is recorded before marking complete.
