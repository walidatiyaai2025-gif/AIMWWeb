# AI WordPress Manager 155.94.5

Maintenance-only patch. No new features were added.

## Fixes

- Clear the previous site's comments immediately when the selected WordPress site changes.
- Prevent a slower, older comments request from overwriting results for the currently selected site.
- Disable refresh when no WordPress site is selected.
- Reset paging and transient messages when switching sites.

## Verification required

Run a clean restore, Release build, and test suite on Windows, then verify `/module/comments` by switching rapidly between two configured sites.
