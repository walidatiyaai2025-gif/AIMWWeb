# AI WordPress Manager 155.94.11

Maintenance-only patch. No new features were added.

## Fixes

- Removed the duplicate `/module/schedules` route from the legacy `AutomationCenter` page so the current schedules workspace is the only component registered for that URL.
- Restricted the legacy automation center to jobs belonging to sites owned by the signed-in account.
- Prevented edit, run, enable/disable, and delete actions from operating on automation jobs outside the owned-site scope.
- Prevented late site-loading and language-change callbacks from rendering after the component is disposed.
- Added duplicate-action guards while save processing is active.
