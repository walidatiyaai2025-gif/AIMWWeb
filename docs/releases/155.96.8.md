# AI WordPress Manager v155.96.8

Reliability patch for application data paths after the development-storage migration.

## Fixed

- `ApplicationPathService` now recognizes both `DOTNET_ENVIRONMENT` and `ASPNETCORE_ENVIRONMENT`.
- Development-mode paths now stay aligned with the first-run setup service when ASP.NET Core is launched with the standard `ASPNETCORE_ENVIRONMENT=Development` setting.
- Legacy development data migration is best-effort: locked logs, SQLite sidecar files, or protected legacy artifacts no longer block application startup.
- Portable mode behavior is unchanged and continues to keep application data beside the executable.

## Validation focus

1. Start with `ASPNETCORE_ENVIRONMENT=Development` and verify data resolves under `%LOCALAPPDATA%\AIWordPressManager\Development`.
2. Clean and rebuild, then verify the same database and setup configuration remain in use.
3. Keep a legacy log or SQLite sidecar file open during startup and verify migration does not crash the application.
4. Verify Production and Portable Mode storage paths are unchanged.
