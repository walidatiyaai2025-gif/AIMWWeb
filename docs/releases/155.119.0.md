# 155.119.0

## Media workflow
- Added server-side media upload validation with a 25 MB limit, extension/MIME checks, and safe file-name handling.
- Added live media metadata editing for title, slug, alt text, caption, and description.
- Added metadata quality guidance and AI-assisted alt-text suggestions for images.
- Added `modified_gmt` conflict protection before metadata updates.
- Added explicit confirmation before permanent WordPress media deletion.
- Reconciles deleted media out of the local cache without advancing the delta-sync cursor.
- Added owner checks to media API operations, including AI and bulk request endpoints.
- Global Media now links to the site Media Manager for optimization and deletion workflows.
- Added automated media upload and concurrency policy tests.

## Boundary
Media optimization in this release means WordPress metadata, SEO/accessibility fields, and AI alt text. Binary recompression, resizing, and transcoding are not performed.

## Compatibility
No database migration is required. Existing media, content, and synchronization records remain compatible.
