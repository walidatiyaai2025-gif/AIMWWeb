# AI WordPress Manager 155.94.14

Maintenance-only installer reliability patch.

## Fixed

- Prevented benign native stderr output from Git and .NET from being treated as a terminating PowerShell error when the native process exits successfully.
- Avoided running `git switch` when the repository is already on the requested branch.
- Uses `git switch --quiet` only when an actual branch change is required.
- Preserved exit-code-based failure detection for real Git and .NET failures.
- Kept automatic selection of the tracked solution closest to the repository root.
- Removed the duplicated installer banner from `Install-First-Time.bat`.

No application features were added.
