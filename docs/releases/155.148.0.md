# AIMWWeb 155.148.0 — PayPal configuration foundation

Canonical feature: `BIL-007`
Tracking issue: #144

## Delivered

- Sandbox/live configuration stored through the existing application settings store.
- Client secret protection through `ISecretProtectionService`; safe reads expose only whether a secret exists.
- Separate trusted runtime configuration provider for decrypted credentials.
- Secret preservation, rotation, and clear behavior; clearing also disables the integration.
- Sandbox/live API endpoint selection and sanitized OAuth configuration diagnostics.
- Diagnostic success requires a valid token response, while token values and response bodies are never persisted or returned.
- Permission-enforced Web administration boundary with security audit events that exclude credential material.
- Persistence and Infrastructure DI registrations.
- Automated tests for encryption, safe reads, secret lifecycle, endpoint selection, request shape, and sanitized diagnostics.

## Boundaries

No checkout, webhook processing, subscription synchronization, plan changes, billing UI, or stored access tokens are introduced in this release.

Final merge remains conditional on the exact PR head passing all required repository gates with zero unresolved review threads.
