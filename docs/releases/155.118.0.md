# 155.118.0

## Content bulk operations
- Added current-page multi-select to the global Posts and Pages explorers.
- Added Publish, Pending, Draft, and Private bulk status actions.
- Multi-site selections are split into independent per-site Execution Center jobs.
- Added owner-scoped preflight validation before multi-site operations.
- Added confirmed bulk trash workflow for global Posts and Pages.
- Added a 100-item safety limit, target validation, normalization, and de-duplication.
- Added automated policy tests for bulk selection safety and grouping.

## Compatibility
Existing site-scoped content editing, synchronization, and bulk operations remain unchanged. No database migration is required.
