# Release 155.126.0

## AI-001 — SEO audit execution

This release turns the existing SEO analysis workspace into a tenant-safe, persistent audit workflow with recent history that matches the score shown to the user.

### Highlights
- Live SEO analysis is owner-scoped at the service boundary.
- Audit latest/run/save/history operations require the authoritative owner identity.
- Existing SQLite `SeoAuditIssues` and `SeoAuditSnapshots` tables are reused; no schema migration is required.
- A completed full audit saves the exact visible `SeoRuleEngine` score and issue set instead of rerunning a different scoring model for history.
- Persisted issue targets are validated against synchronized content before save.
- Latest audit summary is sourced from the latest stored snapshot.
- The SEO workspace displays the last 12 saved audits with score, timestamp, audited items, and severity counts.
- Execution Center tracking remains part of the full-audit workflow.
- Arabic/English, RTL/LTR, responsive layout, and existing SEO workspace styling are preserved.

### Security
- Foreign SiteIds cannot be analyzed through the SEO web service.
- Foreign owners cannot load, save, run, or inspect SEO audit history.
- Missing/foreign sites return `NotFound` without exposing tenant existence.
