# AI WordPress Manager 155.94.6

Maintenance-only patch. No new features were added.

## Fixes

- Prevented stale WordPress user responses from replacing results after the selected site, search, role, or page changed.
- Cleared previous user results immediately when the selected site changed.
- Prevented pending user requests and language-change callbacks from updating a disposed Blazor component.
- Kept the loading indicator tied only to the latest active request.

## Verification

Run a clean Release build and test suite, then switch rapidly between two sites in `/module/users` and verify that only the latest site's users remain visible.
