# 156.0.1 — Site status build compatibility

## Work item
Build stabilization — `SiteConnectionStatus.NotTested` / `Unknown` compatibility.

## Problem
A local Visual Studio build reported CS0117 in `Sites.razor` because the UI referenced `SiteConnectionStatus.NotTested` while the local Domain project did not expose that member.

## Repository state
The current branch keeps `NotTested = 0` as a compatibility alias of `Unknown` and the current `Sites.razor` uses `Unknown` for filtering. This preserves older UI/database semantics while allowing current code to use the canonical `Unknown` name.

## Hardening
Added an automated domain test proving that `NotTested` and `Unknown` remain the same persisted enum value. This prevents a future enum cleanup from silently reintroducing the build/data compatibility regression.

## Verification
