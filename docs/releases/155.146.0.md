# AIMWWeb 155.146.0 — Subscription lifecycle policy engine

Canonical feature: `BIL-004`
Tracking issue: #140

## Delivered

- Added deterministic provider-neutral policy evaluation for trial expiry, past-due grace, grace expiry, suspension and cancel-at-period-end expiry.
- Policy never infers `Active` from elapsed time and never calls a payment gateway.
- Past-due subscriptions use the internal plan `GracePeriodDays`; zero grace suspends immediately, elapsed grace suspends, and valid grace transitions persist an explicit deadline.
- Trial expiry without explicit activation becomes `Expired`; cancel-at-period-end becomes `Expired` only after the persisted current-period end.
- Suspended and terminal Expired states are no-op without an explicit external/admin decision.
- Added bounded batch evaluation and a background worker with per-subscription failure isolation.
- Every automatic status change is applied through the existing audited `IAccountSubscriptionService`, preserving atomic transition history.
- Added tests for conservative activation behavior, configured grace calculation, zero/elapsed grace, cancellation boundaries, terminal no-op behavior, audited/idempotent execution, bounded batch behavior and account/plan data preservation.

No schema change, gateway integration, product-data deletion, checkout/webhook behavior or product-module entitlement enforcement is introduced.
