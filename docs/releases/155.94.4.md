# AI WordPress Manager 155.94.4

Maintenance-only release. No new features were added.

## Fixes

- Prevented the Execution Center periodic refresh loop from racing with component disposal.
- Ignored late language-change callbacks after the Execution Center component has been disposed.
- Added a safe fallback for copying task identifiers when the Clipboard API is unavailable, including HTTP environments.
- Prevented invalid URL hashes from leaving every development dashboard tab hidden.
- Delayed CSV object URL cleanup until after the browser starts the download.
- Kept the development dashboard usable when a data refresh fails instead of replacing the entire page.
- Corrected HTML escaping used by dynamically rendered development status values.

## Scope

This release contains reliability and lifecycle corrections only. Feature status and product scope were not changed.
