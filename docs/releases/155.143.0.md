# AIMWWeb 155.143.0 — Subscription plan catalog foundation

Canonical feature: `BIL-001`
Tracking issue: #134

## Delivered

- Added the provider-neutral `SubscriptionPlan` domain model with immutable stable plan code, bilingual names/descriptions, monthly/yearly billing interval, price/currency, trial/grace policy, enabled state, deterministic sort order, and optional opaque gateway mapping identifiers.
- Added domain validation for plan-code syntax, three-letter currency codes, billing interval, non-negative bounded prices, trial/grace bounds, content lengths, and sort order.
- Added `ISubscriptionPlanCatalog` as the application contract for ordered enabled-plan reads and explicit administrative create/update/enable-disable operations.
- Added the durable EF Core catalog implementation with case-insensitive normalized-code uniqueness and database-backed duplicate race protection.
- Added SQLite migration `20260818183000_AddSubscriptionPlanCatalog`. Existing non-SQLite initialization continues to use the repository's provider-native generated DDL plus missing-table planner rather than replaying SQLite-shaped migrations.
- Registered the catalog through Persistence DI.
- No commercial plans or prices are seeded. An unconfigured catalog is intentionally empty-safe.
- No PayPal dependency and no entitlement model is introduced in this release; those remain `BIL-006+` and `BIL-002` responsibilities respectively.
