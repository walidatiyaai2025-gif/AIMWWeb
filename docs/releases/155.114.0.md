# 155.114.0 - Persistent Synchronization History

- Added durable per-site synchronization history keyed by the exact `Site.Id`.
- Synchronization attempts now persist `Running`, `Completed`, `Skipped`, or `Failed` lifecycle states.
- History records include start/end timestamps, downloaded-record counts, skip state, and a bounded operational message.
- Added EF Core configuration and migration `20260809094500_AddSiteSyncRuns` with cascade cleanup when a site is deleted.
- The synchronization workspace now displays the latest 15 attempts for the selected site profile in Arabic or English.
- No-change delta checks are recorded as skipped runs instead of disappearing from operational history.
- Failed synchronization attempts are recorded without replacing the original synchronization exception if history persistence also fails.
- Added regression tests for synchronization-run state transitions and failure-message bounds.
