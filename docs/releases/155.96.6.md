# AI WordPress Manager v155.96.6

Setup launcher reliability patch.

## Fixed

- `Install-First-Time.bat` now detects Git's `dubious ownership` protection before bootstrapping the latest Setup Tool.
- When Git reports dubious ownership, only the exact installation repository is added to the current user's `safe.directory` list.
- The launcher retries normal Git operations after the repository is trusted, so it can still load the latest `Setup-Tool.ps1` from `origin/<branch>` instead of silently falling back to an outdated local script.
- Temporary Git diagnostics are cleaned up after bootstrap.

## Validation focus

1. Repository owned by the current Windows user.
2. Repository installed/copied by an elevated Administrator account and opened by a standard account.
3. Online bootstrap to the latest Setup Tool.
4. Offline fallback to the local Setup Tool.
