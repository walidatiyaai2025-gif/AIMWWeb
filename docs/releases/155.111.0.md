# 155.111.0 - Public Welcome Landing

- `/welcome` is now explicitly public and can be opened without signing in.
- The global authenticated fallback policy remains in force for operational application pages and APIs.
- Anonymous visitors no longer invoke user-scoped dashboard services or expose WordPress site/content/job/synchronization data.
- Public visitors see safe command-center placeholders plus a Sign in action.
- Authenticated visitors continue to see live command-center metrics.
- Product/module links from the public landing route anonymous users through the login entry point.
- Added regression coverage to keep the Welcome component anonymous.
