# Release 155.132.0 — Navigation Information Architecture & Discoverability

## Scope
UX-002 turns application navigation into a maintained product information architecture instead of duplicated route lists across the shell, command search, recent pages, and workflow shortcuts.

## Highlights
- Added `AppNavigationCatalog` as the single server-side source for workspace groups, routes, bilingual names/descriptions, search aliases, sidebar visibility, and administrator-only visibility.
- Rebuilt the primary sidebar and command palette from the unified catalog.
- Clarified workspace taxonomy: Overview, Content, SEO & Approvals, AI Workspace, Automation & Operations, Reports & Insights, and System & Account.
- Surfaced Automation Center and Notification Inbox in primary navigation.
- Added account and administration destinations to global discovery while filtering administrator-only destinations by the authenticated role.
- Expanded command search beyond page names to localized descriptions, capability keywords, and route paths.
- Grouped search results by workspace and added localized context plus route hints.
- Reworked Recent/Favorites so its authorized route catalog comes from the server navigation catalog through JS interop rather than a stale JavaScript list.
- Added desktop/tablet topbar access to Recent/Favorites while keeping the floating launcher for mobile only and retaining `Ctrl+Shift+P`.
- Refreshed Quick Actions around high-value site, content, AI, planning, automation, execution, synchronization, SEO, notification, and reporting workflows.
- Added automated navigation catalog regression coverage.

## Security and compatibility
- Navigation does not grant authorization; page/API authorization and tenant ownership remain authoritative.
- Administrator-only catalog destinations are omitted from non-administrator global discovery.
- Recent/Favorites stores only route preferences locally and contains no tenant content.
- No database migration.
- No API contract, authentication, AI orchestration, billing, persistence, or WordPress execution behavior change.
- Arabic RTL, English LTR, light/dark modes, and configurable accent themes remain supported.
