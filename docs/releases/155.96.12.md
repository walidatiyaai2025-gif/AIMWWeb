# AI WordPress Manager v155.96.12

Branch: `main`

## Maintenance focus

This patch hardens first-run database configuration recovery without adding new application features.

## Fixes

- Validates the existing `setup.database.json` before ASP.NET Core loads it as a configuration source.
- Preserves malformed setup JSON as `setup.database.invalid-<timestamp>.json` for diagnostics instead of allowing startup to fail before `/setup` can open.
- Replaces a malformed active setup file with a safe `SetupComplete=false` configuration so the application returns to the setup wizard.
- Detects a completed SQLite configuration that points to a missing database file and marks setup incomplete instead of silently creating a new empty database.
- Keeps the configured SQLite connection string available for recovery while preventing automatic initialization against a missing file.
- Preserves malformed legacy Development setup configuration separately and returns the application to setup mode.

## Regression coverage

Added tests for:

- malformed setup JSON recovery and backup preservation;
- missing SQLite database detection without silent database creation;
- an existing SQLite database leaving a completed setup unchanged.
