# 155.116.0 - Multi-site Bulk Actions

- Added multi-select controls to the Sites workspace.
- Added Select Visible / Clear Visible behavior scoped to the current search and status filter.
- Added bulk Retest, Enable, Disable, and confirmed Delete actions.
- Added ownership-safe backend validation for the complete selected site set before mutation.
- Limited each bulk operation to 100 unique site profiles.
- Added responsive selected-card and checkbox visual states using the existing bulk action framework.
- Added regression coverage for selection normalization, bulk limits, ownership pre-validation, and soft-delete behavior.
