# AI WordPress Manager v155.96.4

Maintenance and security hardening for the first-run database setup flow.

## Fixed

- Server database connection strings are now encrypted at rest before they are written to `setup.database.json`.
- SQL Server, PostgreSQL, MySQL, and MariaDB credentials are resolved through the existing `ISecretProtectionService` only when a DbContext is created.
- SQLite remains backward-compatible and stores only its local database file path in the readable connection string.
- Existing installations that still use `Database:ConnectionString` continue to work.
- Startup recovery now preserves `Database:ProtectedConnectionString` instead of replacing or exposing it.
- Database setup failures keep the encrypted credential payload while returning the application to setup mode.

## Validation focus

1. Fresh SQLite setup.
2. Fresh SQL Server/PostgreSQL/MySQL/MariaDB setup.
3. Restart after successful server-database setup.
4. Temporary database outage followed by setup recovery.
5. Upgrade from a legacy setup file that contains `Database:ConnectionString`.
