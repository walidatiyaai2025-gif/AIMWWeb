# Release 155.137.0 — UX-007 Feedback States

## Summary

Release `155.137.0` completes UX-007 with exactly 100 tracked implementation tasks focused on loading, empty, success, warning, cached/stale, partial-failure, retry, and error-state UX.

## Shared feedback-state system

- Added `AppStatePanel` for blocking and section-level feedback with normalized state taxonomy, semantic live regions, recovery guidance, guarded retry, freshness metadata, and optional technical details.
- Added `AppStateBanner` for retained-content feedback such as cached/stale snapshots and partial failures without hiding successful content.
- Added `AppSkeleton` for structured loading placeholders with bounded line count and reduced-motion behavior.
- Routed existing `AppLoading` and `AppEmptyState` through the shared state contract while preserving existing call sites.

## Accessibility and responsive behavior

- Error states are assertive; normal loading, empty, informational, warning, cached, and partial states use polite status semantics by default.
- State meaning uses icons, text, and non-color leading-edge treatment rather than color alone.
- Shared styling uses logical properties for RTL/LTR, wraps long recovery/diagnostic text, stacks actions on narrow screens, supports forced colors, and disables spinner/skeleton animation for reduced motion.
- Generic service failures are not falsely classified as offline; the offline state is available only for consumers that can truthfully determine connectivity state.

## AI Usage adoption

- First load now uses the shared loading state with skeleton placeholders.
- Initial load failure now uses an actionable error state with retry and recovery guidance.
- Null usage snapshots use an actionable empty state linked to AI Center.
- Existing successful telemetry remains visible while a refresh is running.
- Failed refreshes retain the previous successful snapshot and show cached/stale feedback with the last successful refresh time.
- Failed AI calls surface as a partial-failure banner while successful telemetry remains visible.
- Provider and operation subsection empties now use the shared non-blocking empty-state contract.
