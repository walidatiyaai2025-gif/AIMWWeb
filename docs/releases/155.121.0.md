# AI WordPress Manager 155.121.0

## Background tenant identity
- Hosted automation now resolves the current owner of its target WordPress site before execution.
- Bulk content background operations use the same owner propagation model.
- Existing site ownership guards continue to protect WordPress API, synchronization, and editing calls inside workers.

## Security
- Authenticated HTTP identity has precedence over background execution identity.
- Background execution carries no roles and cannot satisfy administrator authorization.
- Deleted or ownerless sites fail closed.
- No automation SQLite migration is required; site ownership is resolved from the authoritative application database at execution time.
