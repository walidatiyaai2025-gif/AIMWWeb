# AI WordPress Manager v155.105.0

## IDN-008 — Application user administration

Adds an administrator-only workspace for managing local application accounts without changing the existing WordPress user-management screen.

### Delivered
- Search and list application users with active, lockout, failed-attempt, role, and last-login state.
- Create application users with password-strength validation and ASP.NET Core password hashing.
- Edit usernames and the existing Administrator/User role boundary.
- Enable and disable accounts.
- Unlock accounts and clear failed-login state.
- Reset passwords and clear lockout state.
- Review recent login-audit records per application user.
- Bilingual Arabic/English responsive administration UI.

### Security guards
- All service operations require an authenticated Administrator role; UI authorization is not the only enforcement layer.
- A signed-in administrator cannot disable or demote their own account.
- The last active administrator cannot be disabled or removed from the Administrator role.
- Plaintext passwords are never persisted.
- Granular roles and permissions remain explicitly scoped to IDN-009.

### Compatibility
- No database schema migration is required.
- The existing WordPress UsersManager workflow is unchanged.

### Verification
A clean GitHub Actions build and complete automated test run are required before IDN-008 is marked completed.
