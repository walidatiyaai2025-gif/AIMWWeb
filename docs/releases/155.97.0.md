# 155.97.0 — Site email recipient foundation

## Scope

Begins Phase 10 / `EML-001`: one to three notification email recipients per owned WordPress site.

## Implemented

- Added `SiteEmailRecipient` domain entity with owner, site, normalized email, display label, enabled state, timestamps, and concurrency token.
- Added EF Core mapping, unique `(SiteId, NormalizedEmailAddress)` constraint, owner/site index, and cascade relationship to `Site`.
- Added SQLite compatibility table/index creation for existing SQLite installations.
- Added tenant-safe `SiteEmailRecipientService` with read/add/update/delete operations.
- Enforces a maximum of three recipients per site.
- Rejects duplicate addresses case-insensitively.
- Rejects access to sites not owned by the authenticated application user.
- Added bilingual `SiteEmailSettings` workspace at `/sites/{siteId}/email-settings` and `/module/site-email-settings`.
- Added an Email notifications card to the existing Site Settings page.
- Added service tests for maximum count, duplicate prevention, tenant isolation, update/disable, and delete.

## Status

`EML-001` remains **in_progress** until clean restore/build/tests and runtime smoke verification complete. Existing non-SQLite databases also need an explicit schema-upgrade path; fresh non-SQLite databases include the entity through the current EF model.
