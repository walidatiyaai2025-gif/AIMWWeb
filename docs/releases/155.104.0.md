# AI WordPress Manager v155.104.0

## EML-010 — Email delivery history

This release adds the first tenant-safe delivery history workspace on top of the durable email outbox introduced in v155.102.0.

### Implemented

- Added `EmailDeliveryHistoryService` scoped to the authenticated account.
- Added `/email/history` with filters for site, delivery status, and correlation ID.
- Displays durable states: `Queued`, `Sending`, `RetryWaiting`, `Sent`, `Failed`, and `Cancelled`.
- Displays attempt count, next attempt, sent timestamp, correlation ID, idempotency key, and sanitized last error.
- Message details expose delivery attempts with sanitized provider summary/error information only.
- History responses do not expose SMTP credentials, protected secrets, message HTML/text bodies, or recipient snapshots.
- Added navigation from Site Settings → Email notifications → Delivery history.
- Added regression coverage proving account isolation for history and message details, plus status/correlation filtering.

### Validation status

`EML-010` remains `in_progress` until a clean Release build/test run and runtime review are completed on the target Windows environment.
