# Release 155.124.1

## Hotfix
Fix SQLite synchronization startup/schema compatibility for `SiteSyncRuns`.

### Fixed
- EF Core now discovers `20260809094500_AddSiteSyncRuns` for `AppDbContext`.
- Existing SQLite databases that have not yet applied the sync-history migration receive the table during normal database initialization.
- Regression tests verify both migration discovery and physical `SiteSyncRuns` table creation before synchronization writes history.

### User-visible error resolved
`Microsoft.Data.Sqlite.SqliteException: SQLite Error 1: 'no such table: SiteSyncRuns'.`
