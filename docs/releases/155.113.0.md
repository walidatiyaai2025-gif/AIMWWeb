# 155.113.0 - Site Onboarding Profile Consistency

- Updated `/sites/connect` guidance to match the reusable site-profile model: the same WordPress URL may be used by multiple independent profiles.
- Clarified that each profile keeps its own credentials and settings.
- Fixed failed connection-test retries so edits to the site name or URL are persisted to the already-created profile before the next test.
- Retrying onboarding now updates the same `Site.Id` rather than silently keeping stale profile data or creating another profile.
- Added regression tests for first-save create behavior and existing-profile retry/update behavior.
- Existing ownership enforcement, credential encryption and synchronization retry behavior remain unchanged.
