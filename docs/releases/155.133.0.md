# Release 155.133.0 — UX-003 Responsive Mobile/Tablet Application Shell

## Summary

Release `155.133.0` completes UX-003 and turns the shared application shell into a production responsive experience across desktop, tablet, phone, and short-landscape layouts.

## Highlights

- Unified tablet/mobile off-canvas navigation through a shared `1024px` responsive breakpoint.
- Kept responsive drawer state independent from the persisted desktop collapsed-sidebar preference.
- Responsive navigation starts closed and reconciles safely across resize and orientation changes.
- Added Razor-owned, localized drawer close and backdrop controls, route-click close, and Escape close behavior.
- Added `viewport-fit=cover`, device safe-area insets, dynamic viewport height units, and safe positioning for shell overlays and popovers.
- Added progressive topbar condensation for tablet, phone, narrow-phone, and very narrow-phone widths.
- Added short-landscape shell behavior that prioritizes navigation and content when vertical space is constrained.
- Added shared overflow containment while preserving component-owned scrolling.
- Added opt-in `MobileRowTemplate` support to `AppDataGrid` so dense phone workspaces can render card rows while retaining the same search, sorting, paging, selection, and export state.
- Hardened shared data-grid touch scrolling and shared dialog body/footer overflow behavior.
- Added responsive-shell regression contract tests covering breakpoint parity, state persistence, drawer controls, safe areas, viewport sizing, overflow, landscape, mobile grid alternatives, and dialog safety.

## Compatibility

- No database migration.
- No domain, persistence, API, authentication, tenant ownership, AI orchestration, billing, or WordPress execution behavior changed.
- Existing dark/light modes and configurable accent themes remain authoritative.
- Arabic RTL and English LTR share the same logical responsive layout contract.
- Existing `AppDataGrid` consumers remain source-compatible; `MobileRowTemplate` is optional.
