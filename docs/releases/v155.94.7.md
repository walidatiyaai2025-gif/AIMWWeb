# AI WordPress Manager v155.94.7

Maintenance-only patch for the comments workspace.

## Fixes

- Prevents outstanding WordPress comment requests from mutating component state after the page is disposed.
- Invalidates active comment loads during disposal.
- Prevents the language-change event from invoking UI updates after disposal.
- Keeps site-list initialization and refresh results from being applied after navigation away from the page.
- Makes component disposal idempotent.

No new features were added.
