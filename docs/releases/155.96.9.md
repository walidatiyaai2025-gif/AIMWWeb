# AI WordPress Manager v155.96.9

Setup and recovery reliability patch.

## Fixed

- `Run application only` no longer assumes that a previous build artifact exists.
- `dotnet run` is now allowed to restore/build incrementally when required, so Run mode works after a clean build output or a fresh clone.
- Install/update followed by Run remains efficient because the second build is incremental when the application was already built successfully.
- Setup Tool control flow was simplified while preserving install/update, pull, push, build, test, run, diagnostics, safe-directory handling, local-change protection, and local-commit backup behavior.

## Validation focus

1. Delete tracked `bin`/`obj` output, then select `Run application only`.
2. Run immediately after a fresh clone without running Build first.
3. Run after `Install first time OR update existing installation` and confirm startup succeeds without missing DLL errors.
4. Confirm existing diagnostic logging and Git safety prompts still work.
