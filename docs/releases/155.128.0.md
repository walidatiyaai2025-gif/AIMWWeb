# Release 155.128.0

## AI-003 — Prompt template registry

This release completes the prompt-template registry with durable administration and append-only version history while preserving the existing synchronous runtime lookup contract.

### Highlights
- Added a durable `VersionedAIPromptRegistry` stored atomically under the application Data directory.
- The existing ten English/Arabic built-in prompts are seeded at revision 1 and are never overwritten when administrators customize them.
- Added an administrator-only bilingual management workspace at `/settings/ai-prompts` and linked it from Settings.
- Administrators can create custom templates, edit English/Arabic titles and prompts, enable or disable templates, review all revisions, and restore a prior revision.
- Template keys become stable identities after creation so existing runtime callers are not broken by an accidental rename.
- Restoring a historical revision creates a new revision instead of rewriting history.
- Saving unchanged content is idempotent and does not create duplicate revisions.
- Disabled templates are removed from runtime `GetAll` results and resolve to an empty instruction while their full history remains available to administrators.
- A malformed registry file is quarantined when possible and the built-in catalog is recovered safely.

### Persistence model
Prompt templates are application-global configuration, matching the existing singleton prompt-registry semantics. The registry uses an atomic JSON document in the same managed application Data directory as other local application data. This avoids an unnecessary relational schema migration while still providing crash-safe replace semantics and restart persistence.

### Security and governance
- Prompt management requires the `Administrator` role.
- The Settings navigation entry is visible only to administrators.
- Every material change records revision number, UTC timestamp, actor, enabled state, bilingual titles, and bilingual prompt bodies.
- Runtime lookup remains read-only through `IAIPromptRegistry`; management operations are separated through `IAIPromptTemplateStore`.
- No prompt revision is destructively deleted by the UI.

### Regression coverage
- Built-in bilingual seed catalog and persisted registry creation.
- Persistence across a new registry instance/application restart.
- Idempotent unchanged save behavior.
- Update and restore append new immutable revisions.
- Disabled templates are excluded from runtime exposure while history is preserved.
- Invalid custom keys are rejected.
