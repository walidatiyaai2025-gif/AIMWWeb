# Release 155.128.0

## AI-003 — Versioned prompt template registry

This release turns the existing built-in AI prompt dictionary into an administrator-managed, bilingual, versioned runtime registry while preserving the original templates as a safe baseline.

### Highlights
- Added a bilingual administrator-only prompt registry workspace at `/settings/ai-prompts`.
- Administrators can create or customize templates, maintain English and Arabic prompt text, and enable or disable runtime use.
- Every save creates an append-only version; restoring an older snapshot creates a new version instead of rewriting history.
- Built-in prompts remain available as version `0` and can be restored into a new managed version.
- Managed prompt history is retained in the existing `ApplicationSettings` store, avoiding a schema migration or parallel persistence model.
- The persisted registry keeps up to 50 saved revisions per prompt.

### Runtime integration
- `/api/ai/prompts` now returns the effective merged registry rather than only the hard-coded dictionary.
- `/api/ai/generate` resolves the effective managed template and rejects missing or disabled prompt keys.
- AI Center now uses the same managed prompt service for discovery and generation.
- Fixed AI Center prompt discovery, which previously serialized a dictionary and attempted to read it as a JSON array.
- Administrator-only REST endpoints expose prompt history, save, and restore operations.

### Validation and safety
- Prompt keys are normalized and limited to ASCII letters, digits, `.`, `_`, and `-`, up to 80 characters.
- Managed prompts require both English and Arabic text, with an 8,000-character limit per locale.
- Disabled templates are hidden from normal discovery and cannot execute through the managed generation path.
- Prompt mutation/history routes and the management page require the `Administrator` role.
- Regression tests cover version creation, immutable history, restore-as-new-version behavior, localization, runtime disablement, built-in restoration, and validation.
