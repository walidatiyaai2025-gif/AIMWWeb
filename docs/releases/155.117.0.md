# 155.117.0 - Safe Direct Content Editing

- Prevented silent post/page overwrite when WordPress content changes after the editor is opened.
- Added optimistic concurrency based on WordPress `modified_gmt`.
- Normal saves now preflight the current remote version before POSTing changes.
- Conflict results preserve the local editor state and skip the update request.
- Successful saves advance the editor concurrency baseline.
- Added supported-status validation and regression coverage for conflict, success, validation, and timezone-equivalent versions.
- Kept advanced compare/merge conflict resolution separate under CNT-012.
