# Release 155.131.0 — Premium Design System & Application Shell Foundation

## Scope
UX-001 establishes the shared UI/UX foundation for the prioritized design workstream tracked in GitHub Issues #46–#55.

## Highlights
- Added `docs/UI_UX_MASTER_PLAN.md` with ten Critical/High UI/UX tasks and a shared UX Definition of Done.
- Added a premium shared application-shell layer that extends the existing theme and `--ui-*` token systems.
- Improved sidebar sizing, navigation grouping, active hierarchy, topbar composition, content gutters, touch targets, focus visibility, and reduced-motion behavior.
- Added mobile compatibility rules that preserve the existing off-canvas sidebar and neutralize conflicting legacy horizontal navigation behavior.
- Added keyboard skip navigation and accessible names/semantics to shell controls and command search.
- Exposed AI Center, Content Planner, AI Providers, Prompt Templates, and AI Usage & Cost in the primary navigation and command palette.
- Expanded command discovery for approvals, schedules, logs/errors, backup/restore, and other production destinations.
- Fixed page-title route resolution so the root `/` command cannot incorrectly label unrelated routes as Dashboard.
- Removed the stale hard-coded `agent/logs-error-center` branch marker from layout CSS. Build version/branch/commit identity remains runtime-driven through `BuildInformationService`.

## Compatibility
- No database migration.
- No domain, persistence, authentication, API, AI orchestration, billing, WordPress, or execution behavior changes.
- Existing theme accent selection and dark/light modes remain supported.
- Arabic RTL and English LTR remain supported.
- Existing account, notification, command-palette, and build-information services remain in place.
