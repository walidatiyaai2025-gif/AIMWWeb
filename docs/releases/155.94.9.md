# AI WordPress Manager v155.94.9

Maintenance-only patch. No new features were added.

## Fixed

- Made the Approval Queue component lifecycle-safe.
- Prevented language-change events from requesting UI renders after the component is disposed.
- Prevented approval/rejection notifications and state writes after navigation away from the page.
- Added duplicate-action guards while an approval decision is already being processed.
- Made disposal idempotent.

## Validation focus

- Open `/approvals`, expand an item, then navigate away while changing language.
- Approve or reject an item and immediately navigate to another page.
- Confirm there are no unexpected Blazor circuit errors and no duplicate approval actions.
