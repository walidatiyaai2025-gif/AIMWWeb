# AIMWWeb 155.145.0 — Audited account subscription state

Canonical feature: `BIL-003`
Tracking issue: #138

## Delivered

- Added the provider-neutral account subscription states `Trialing`, `Active`, `PastDue`, `Grace`, `Suspended`, `Cancelled`, and terminal `Expired`.
- Added one durable current subscription row per account, linked to the internal subscription plan, with trial/current-period timestamps, cancel-at-period-end, grace/cancel/suspend/expiry timestamps, optional opaque provider binding and a monotonic provider-event watermark.
- Added centralized transition legality and stale/duplicate provider-event rejection. Failed transition validation occurs before mutation so an exception cannot leave a tracked entity carrying an invalid partial change.
- Added durable transition audit records for real status changes only. Subscription state and its transition audit are committed in one EF Core unit of work; same-state confirmations do not create fake transition history.
- Added provider-neutral application and persistence services for current-state reads, creation, transitions, lifecycle-period updates, cancel policy, provider-reference binding and bounded transition history.
- Added account/plan validation, unique-current-subscription protection, SQLite migration `20260818190000_AddAccountSubscriptionState`, provider-neutral non-SQLite missing-table compatibility and DI registration.
- Added regression coverage for the state matrix, terminal expiry, one-row-per-owner, atomic audit, no-op transitions, provider-event monotonicity, invalid-transition mutation safety, grace bounds, lifecycle updates and migration artifacts.

## Boundaries

- No provider SDK or provider-specific state names are introduced.
- No automated grace/expiry scheduler is introduced; `BIL-004` owns policy automation.
- No checkout/webhook synchronization is introduced; `BIL-008` through `BIL-010` own provider integration.
- No upgrade/downgrade flow is introduced; `BIL-011` owns plan changes.
- No product-module entitlement enforcement is introduced; `BIL-012` owns enforcement.
- Subscription transitions never delete account, site or content data.
