# AI WordPress Manager v155.96.7

Development storage reliability patch.

## Fixed

- Development-mode application data is no longer stored under `bin/Debug` or `bin/Release` build output.
- Development data now lives under `%LOCALAPPDATA%\AIWordPressManager\Development`.
- SQLite development databases, logs, screenshots, backups, exports, and temporary application data are kept outside `bin/obj` cleanup.
- Existing Development files found beside the old build output are copied forward without overwriting newer destination files.
- `setup.database.json` now uses a stable Development config directory outside build output.
- Legacy Development setup configuration is migrated automatically.
- Existing server-database setup files are preserved as-is during migration, including protected credentials.
- Existing SQLite Development databases are copied to the stable data directory and the migrated setup config is rewritten to point to the stable database path.

## Validation focus

1. Run from Visual Studio in Development mode and complete first-run setup.
2. Clean the solution and rebuild; setup state and SQLite data must remain intact.
3. Upgrade from a Development build that stored data under `bin/.../Data`.
4. Verify existing Development backups and exports remain accessible after migration.
5. Verify Production and Portable Mode paths remain unchanged.
