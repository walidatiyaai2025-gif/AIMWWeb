# AI WordPress Manager 155.94.12

Maintenance-only patch for the Backup & Restore workspace.

## Fixes

- Prevents backup workspace operations from updating the UI after the component is disposed.
- Prevents overlapping create, inspect, preflight, refresh, copy-path, and delete actions.
- Disables backup action controls while an operation is active.
- Handles inspection, preflight, clipboard, refresh, and delete exceptions consistently.
- Prevents language-change events from rendering a disposed component.
- Makes component disposal idempotent.

No new product features were added in this release.
