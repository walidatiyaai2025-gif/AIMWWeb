# 155.120.0

## Synchronization conflict resolution
- Added pre-sync comparison between the local content mirror and live WordPress posts/pages.
- Detects remote updates and remote deletions before replacing the local cache.
- Added side-by-side local/live review, transient defer, and direct-editor merge paths.
- Added confirmed `Accept WordPress` resolution using a forced full synchronization.
- Forced refresh bypasses the delta shortcut so remote deletions can be reconciled into the mirror.
- Remote additions are reported separately and are not treated as conflicts.
- Added deterministic synchronization conflict policy tests, including timezone-equivalent modification timestamps.

## Safety boundary
The local SQLite content cache is a read mirror, not an unpublished draft. This workflow never posts stale cached content back to WordPress. Manual content merges continue through the direct editor with optimistic concurrency protection.

## Compatibility
No database migration is required.
